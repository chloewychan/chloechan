# Chloe Chan Portfolio

A personal portfolio website built with HTML, CSS, TypeScript, and Tailwind CSS.

## Setup

### Prerequisites
- Node.js (v14 or higher)
- npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/chloechan/chloechan.ca.git
cd chloechan.ca
```

2. Install dependencies:
```bash
npm install
```

## Development

Start the development server:
```bash
npm run dev
```

The site will be available at `http://localhost:8000`

## Building

Compile TypeScript to JavaScript:
```bash
npm run build
```

## Production

Start the production server:
```bash
npm start
```

## Project Structure

- `index.html` - Main HTML file
- `script.ts` - TypeScript source code
- `script.js` - Compiled JavaScript (auto-generated)
- `styles.css` - Custom CSS styles
- `tsconfig.json` - TypeScript configuration

## Technologies

- HTML5
- CSS3
- TypeScript
- Tailwind CSS
- http-server
